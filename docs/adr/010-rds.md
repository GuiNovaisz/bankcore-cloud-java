# ADR-010: Owned databases on one managed PostgreSQL instance

Status: accepted for foundation. Date: 2026-11-21.

Separate logins/databases keep ownership real while controlling portfolio costs. One instance remains a shared infrastructure failure domain; separate instances are a production isolation option. RDS supports backups/PITR/Multi-AZ; single-AZ default never claims HA.

Consequences: implement/test the chosen boundary and retain the documented limitation; re-evaluate with measured workload or an explicit production requirement rather than adding technology for its name.
