# ADR-004: SQS standard delivery

Status: accepted for foundation. Date: 2026-11-21.

Use AWS-native standard SQS with bounded visibility, redrive3 and DLQ. Accept duplicates/reordering and protect the derived consumer with an inbox. Kafka/FIFO/exactly-once claims are unnecessary for commutative projection deltas. LocalStack validates API behavior, not live AWS deployment.

Consequences: implement/test the chosen boundary and retain the documented limitation; re-evaluate with measured workload or an explicit production requirement rather than adding technology for its name.
