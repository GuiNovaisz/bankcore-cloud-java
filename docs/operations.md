# Local operator runbook

Start: scripts/dev-up.ps1. It creates ignored random credentials and Prometheus password file, builds serially, then waits for health. Each service runs as nonroot Java 21 with exec-form entrypoint. SIGTERM and a 35-second container stop window exceed Spring's 25-second graceful HTTP window. Consumers acknowledge only committed projection work; an interrupted transaction is retried safely.

## Sample transfer (PowerShell 7)
~~~powershell
$values=@{}
Get-Content .env | ForEach-Object { $k,$v=$_ -split '=',2; $values[$k]=$v }
$auth=[Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes("operator:"+$values.OPERATOR_PASSWORD))
$headers=@{Authorization="Basic $auth"}
$base='http://localhost:28180'
$a=[guid]::NewGuid().ToString(); $b=[guid]::NewGuid().ToString()
foreach($id in @($a,$b)){
 Invoke-RestMethod "$base/account/accounts" -Method Post -Headers $headers -ContentType application/json -Body (@{id=$id;ownerReference="fixture-$id"}|ConvertTo-Json)
}
Invoke-RestMethod "$base/ledger/admin/funding" -Method Post -Headers $headers -ContentType application/json -Body (@{id=[guid]::NewGuid().ToString();destination=$a;amount='100.00';currency='BRL'}|ConvertTo-Json)
$headers['Idempotency-Key']=[guid]::NewGuid().ToString()
$t=Invoke-RestMethod "$base/transfer/transfers" -Method Post -Headers $headers -ContentType application/json -Body (@{source=$a;destination=$b;amount='80.00';currency='BRL'}|ConvertTo-Json)
Invoke-RestMethod "$base/transfer/transfers/$($t.id)" -Headers $headers
Invoke-RestMethod "$base/ledger/accounts/$a/balance" -Headers $headers
~~~
Poll until COMPLETED or FAILED. A 202 response is durable acceptance, not completion. Reusing the same key/command returns the same logical id. A PROCESSING transfer during an outage must be reconciled, not resubmitted under a new key. To inspect an existing trace, open Grafana → Explore → Tempo and use artifacts/trace-id.txt generated by smoke. Tests save actual trace JSON, not a screenshot.

## Incidents
Outbox backlog: inspect SQS availability/permissions and outbox attempts; restore dependency; publisher retries without money rollback. Do not delete outbox rows. DLQ: inspect schema/version and cause, preserve evidence; fix consumer and explicitly redrive, respecting inbox retention. Cache outage: inspect failure counters; DB fallback is expected, do not restart all services. Pending transfers: inspect service readiness and lookup journal by id; restore dependencies and allow worker reconciliation. Database: stop unsafe traffic, preserve backups, follow disaster-recovery.md. Projection mismatch: drain in-flight traffic/events and rerun audit before planned rebuild.

Shutdown: scripts/dev-down.ps1 stops/removes only this Compose project; volume remains. Full data wipe requires an explicit docker compose down -v by the operator. Do not run it against unrelated projects. Ports are loopback-bound and services have resource limits. If a chosen port is in use, edit host-side port mapping and BANKCORE_BASE_URL, preserving existing processes. CloudView/real AWS dashboards are not fabricated.

Rolling deployment target: previous image/task revision retained, ECS deployment circuit breaker enabled, ALB health gates/deregistration delay. Rollback selects the prior digest/task revision, not a mutable tag. Flyway migrations are forward-only; expand/contract changes must remain compatible with both image revisions. Never assume schema rollback or zero downtime. No actual cloud deployment or rollback has been measured.
